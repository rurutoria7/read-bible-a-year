使徒行傳 8

掃羅殘害召會 → 腓利在撒瑪利亞傳基督與神的國 → 埃提阿伯太監得救

本日進度：使徒行傳 8 章（新約一章）｜材料：恢復本經文＋註解、生命讀經、全書鳥瞰總表、綱要

壹事實速覽

事件脈絡

  1. 逼迫與分散（8:1–3） 司提反殉道那日，耶路撒冷召會大遭逼迫；掃羅殘害召會，逐家進去連男帶女拉去下監；除使徒以外，門徒都分散在猶太和撒瑪利亞各地。
  2. 腓利在撒瑪利亞傳揚（8:4–8） 分散的人往各處去傳神的話為福音；腓利下撒瑪利亞城傳揚基督，行神蹟——污靈被趕、癱瘓瘸腿得醫，城裡大有歡樂。
  3. 西門信主（8:9–13） 素來行邪術、自稱大人物的西門使百姓驚奇；及至眾人信了腓利所傳的福音，連西門也信了、受了浸，常與腓利在一處。
  4. 使徒的印證（8:14–17） 使徒打發彼得、約翰到撒瑪利亞，為信徒禱告、按手，他們就受了聖靈（經綸一面）。
  5. 西門的錯（8:18–24） 西門見按手便有那靈賜下，就拿錢要買這權柄；彼得責備他心不正、苦膽被不義捆綁，叫他悔改離棄這惡。
  6. 埃提阿伯太監（8:26–40） 那靈引導腓利貼近太監的車；太監正念以賽亞五十三章，腓利從那經起向他傳耶穌為福音，太監信而受浸；腓利被靈提去，走遍城邑傳福音直到該撒利亞。

人物與地點

人物 掃羅（逼迫者，後來的使徒保羅）｜腓利（傳福音者，七位服事飯食者之一）｜西門（行邪術者）｜彼得、約翰（使徒）｜埃提阿伯太監（尋求神的人）。

地點 耶路撒冷｜撒瑪利亞城｜迦薩曠野之路｜亞鎖都｜該撒利亞。

本卷鳥瞰座標（取自「全書鳥瞰總表」）

使徒行傳

主題：復活的基督在升天裡，憑著那靈，藉著門徒，為著產生眾召會——神的國——的繁殖。

鑰字：見證人（繁殖）（徒一8）｜神的國（徒二八31）

但聖靈降臨在你們身上，你們就必得著能力，並要在耶路撒冷、猶太全地、撒瑪利亞，直到地極，作我的見證人。（徒一8） 全然放膽宣揚神的國，並教導主耶穌基督的事，毫無阻礙。（徒二八31） 《使徒行傳》鑰節

生命讀經本篇重點

以下照生命讀經原文逐篇摘要，不另加解讀。

第二十一篇（7:1–8:3，本章只讀 8:1–3 耶路撒冷召會的遭害）

  1. 掃羅贊同司提反被殺（7:60「又跪下，大聲喊着說，主阿，不要將這罪歸與他們！說了這話，就睡了。掃羅也贊同他被殺。」），自以為了不起，至終成為帶頭逼迫召會的人。
  2. 8:1 在耶路撒冷的召會大遭逼迫，除使徒以外門徒都分散在猶太和撒瑪利亞各地——這是頭一處在地方上建立的召會，是宇宙召會（基督身體）的一部分。〔關聯〕門徒分散在「猶太和撒瑪利亞」，正走在本卷鑰節徒一8「耶路撒冷、猶太全地、撒瑪利亞…」的路線上。
  3. 8:3 掃羅殘害召會，逐家進去，連男帶女拉去下在監裡。

第二十二篇（8:4–13，傳福音的榜樣）

  1. 8:4 分散的人往各處去傳神的話為福音——藉聖徒的分散（移民）傳福音，是神的主宰，使福音得以開展。〔關聯〕「往各處去傳…為福音」即本卷鑰字「見證人（繁殖）」的實行。
  2. 這腓利不是使徒中的腓力，乃是七個服事飯食者之一；因著他傳福音的職事，顯明為「傳福音者腓利」（二一8「第二天，我們離開那裡，來到該撒利亞，就進了傳福音者腓利家裡，和他同住，他是那七個執事裡的一個。」）。
  3. 腓利傳基督與神的國為福音——傳基督為福音，也傳神的國為福音，與主所作的一樣（可一14–15；路四43）。〔關聯〕「神的國」正是本卷鑰字（徒二八31）。
  4. 神的國＝救主耶穌作生命的種子，撒在信徒裡面，發展為神在神聖生命裡掌權的範圍；所以傳神的國就是傳基督，基督就是神的國。
  5. 聖徒該傳神的話為福音——要被新約的話浸透，用神的話把基督與國度傳輸給人，而不是靠故事例證。

第二十三篇（8:14–35）

  1. 主保留經綸的靈：撒瑪利亞信徒信主時已在素質一面受了聖靈，但經綸一面的靈還沒有降下，要等使徒來按手，將他們帶進與基督身體的聯合。
  2. 福音工作不該向基督的身體獨立——分散的聖徒和腓利作了好工，但主保留經綸的靈，防止他們獨立。〔關聯〕按手使撒瑪利亞召會聯於基督的身體，正是本卷主題「產生眾召會」的實際。
  3. 浸入主耶穌的名裡＝浸入主的人位裡，與釘十字架、復活、升天的基督聯合，與活的主有生機的聯結。
  4. 西門行邪術是為著錢；他見按手便有那靈賜下，就拿錢要買這權柄，彼得責備他「你的銀子和你一同毀壞」，叫他悔改離棄這惡。
  5. 使徒「見證」主的話是用個人對主的經歷作證；「講論」主的話是按主的啟示傳揚並教導。
  6. 腓利離開撒瑪利亞的工作——每當我們建立了一地召會，就該豫備好離開，不把工作留在自己手中。

第二十四篇（8:26–40，向埃提阿伯太監傳福音）

  1. 福音從純血統的猶太人 → 混血的撒瑪利亞人 → 道地的外邦人（埃提阿伯太監），並向南開展到非洲。〔關聯〕這是本卷主題「…直到地極」之繁殖的應驗。
  2. 太監上耶路撒冷去敬拜神，在車上念以賽亞書——他是尋求神、饑渴要神的人；主主宰的安排，叫腓利來接觸他。
  3. 用最好的一段聖經傳福音：太監所念的是賽五三「祂像羊被牽去宰殺」，腓利就從這經起，向他傳耶穌為福音。
  4. 腓利傳福音的一切活動都在那靈的指引之下——不是憑人的策略和規畫，乃憑那靈的帶領和引導。
  5. 水浸的典型事例：太監看見水就要求受浸，指明腓利向他傳了水浸；這事例強調水浸，一點沒有題到說方言。
  6. 水浸與靈浸是一個浸：水象徵三一神、基督、基督的死；靈是實際，水是外在的確認——浸入水裡就是浸入三一神、浸入基督、浸入祂的死，結果浸入基督的身體。

叄自測（先回想，再點開答案）

1八章開頭，耶路撒冷召會遭遇什麼？掃羅作了什麼？門徒如何？

司提反殉道那日，耶路撒冷召會大遭逼迫；掃羅殘害召會，逐家進去連男帶女拉去下監。除使徒以外，門徒都分散在猶太和撒瑪利亞各地。徒 8:1–3

2腓利在撒瑪利亞傳什麼？行邪術的西門後來如何？

腓利傳基督與神的國為福音，並行神蹟（趕污靈、醫癱瘓瘸腿）。行邪術的西門也信了、受了浸，常與腓利在一處。徒 8:4–13

3撒瑪利亞信徒為何要等彼得、約翰按手，才在經綸一面受聖靈？

主保留經綸的靈，要等使徒來按手，把撒瑪利亞的召會帶進與基督身體的聯合，防止福音工作向身體獨立。徒 8:14–17；生命讀經 23

4腓利如何引導埃提阿伯太監得救？太監念的是哪段經？

那靈叫腓利貼近太監的車；太監正念以賽亞五十三章（「祂像羊被牽去宰殺」），腓利就從這經起向他傳耶穌為福音；太監信而受浸。徒 8:29–38
